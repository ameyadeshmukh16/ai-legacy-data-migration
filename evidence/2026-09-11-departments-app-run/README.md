## Why this run matters

`evidence/2026-09-06-departments-full-run/` (the only other committed live run) was
captured on commit `40e93dc`, *before* the validation-hardening round. Its README carries
a "Version note" explicitly disclosing that value-distribution reconciliation, the
raw-data post-extraction check, `sqlglot` AST validation, reviewer identity, and the
run-lifecycle/rollback events were **not** exercised in a committed live run — only
covered by the automated test suite.

**This run closes that gap.** It exercises the fully hardened code, end to end, live:

- `distribution_reconciliation_completed` fires and passes (`data/distribution_reconciliation_report.json`,
  reproduced here).
- `human_mapping_approved` carries `reviewer_id` / `reviewer_role` (see below).
- The executor's `table_loaded` event shows the two-step SQL split from the hardening
  work: a raw `extract_sql` (pre-transform, for the post-extraction GX checkpoint) and a
  separate `select_sql` that applies the approved rule logic.
- `run_started` / `run_completed` lifecycle events bracket the run.

It was also the first time the pipeline was driven through the **Streamlit application
layer** rather than the CLI (`python -m workflow.langgraph_orchestrator`) — the
Configuration → Human Review → Run Status flow described in `README.md`'s "Application"
section, proving the app layer genuinely drives the unmodified LangGraph workflow rather
than a re-implementation.

## Independently re-verifying the hash chain

This run's 19 events are a *slice* of the live chain (they don't start at `GENESIS`), so
verify them as an internally-consistent sub-chain anchored at the recorded starting hash:

```python
import json, hashlib

events = json.load(open("evidence/2026-09-11-departments-app-run/audit_log_snapshot.json"))
prev = events[0]["previous_hash"]  # this run's events chain onto prior runs; not GENESIS
for e in events:
    assert e["previous_hash"] == prev
    canonical = json.dumps({k: v for k, v in e.items() if k != "hash"}, sort_keys=True, separators=(",", ":"))
    assert e["hash"] == hashlib.sha256((prev + canonical).encode()).hexdigest()
    prev = e["hash"]
print(f"This run's {len(events)} events chain together correctly.")
```
